# 真人拍照指导评估

2026-11-07 起的测试设计。以下不是已通过的结论，不引用此前实验，也不自动增加 prompt 规则。

## 指导模式

- 确认预览和模型输入没有虚拟角色。记录用户拍摄目标、人物朝向、镜像状态，以及“左 / 右”指本人还是画面；含义未明确时不直接判断方向对错。
- 分别检查场景观察、构图、姿势和表情建议是否符合用户目标。标签有效不代表建议正确，角色位移不代表真人移动。
- 连续过程覆盖初始画面、未执行建议、按建议调整、反方向调整、到位和撤回目标；观察模型是否依据新画面判断、到位后停止纠正。
- 模式切换会清空模型上下文，跨模式测试记录目标和方向信息是否重新提供，不假定已经继承。

## 合照模式

- 分别验证邀请生成 mode 标签、成功加载会话、角色与真人同框、实际动作和互动内容；一个环节通过不代表全部通过。
- 分别记录用户要求真人调整姿势、要求角色换位或改变画面占比的情形，核对 teleport 的落点与大小，以及 rotate、layer、tachie 是否符合构图目标。
- 覆盖否定、取消、聊天、重复邀请和返回指导。无动作也可能正确，不强制每轮保持标签。
- 换位时，检查角色是否从旧位置消失并以目标大小在新位置显现。观察角色透明处的背景、真人对角色的遮挡，以及连续换位后最后一次指定的构图。

## 证据范围

合成图片标注为合成图文实验，合成语音标注为重放，模拟连接和静态图像单独报告。真人实时闭环应包含真实摄像头、参与者输入的拍摄目标以及其按反馈做出的实际调整。记录样本数、失败、无回复、原始输出和真实位置变化；短测不表述为长期稳定。
