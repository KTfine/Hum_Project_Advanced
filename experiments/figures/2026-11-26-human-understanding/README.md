# Human-understanding result charts

All values are read directly from the frozen formal metrics files under
`D:\AI_cache\hum_project_evaluation\runs`.

- `activity-accuracy`: Penn Action activity-classification accuracy.
- `pose-pck-at-020`: Penn Action pose PCK@0.20 only.
- `emotion-accuracy`: RAVDESS emotion-classification accuracy.
- `human-understanding-summary`: the three charts in one figure.
- `chart-data.csv`: exact plotted values and model identifiers.

PNG files are intended for slides and reports; PDF files are vector versions.
