# 入镜与跟随站位回放

2026-11-21，Asia/Shanghai。将入镜和跟随使用的站位模块从 `shoulder.py` 改名为 `beside.py`，移除仅供旧肩后测试调用的入口。比较目标是已有站位在改名和清理前后的成片及参数。

对照组从提交 `1fd8dde` 加载当时的 `side_placement()`，试验组加载工作区的同名函数。两组均使用当前小白龙立绘、同一客户端、场景分析和 PNG 快门。输入为既有平视自习室的左、右两张生成图，以及从这两张图分别取得的半身裁切。

| 取景 | 默认入镜 | 换边后叫她跟来 | 原地再次叫她跟来 |
|---|---|---|---|
| 全身 | 一致 | 一致 | 一致 |
| 半身 | 一致 | 一致 | 一致 |

六组的 PNG 文件、脚点、倍率、投影站高和姿势全部相同。使用本地画面回放和指令执行，没有调用对话 API。复跑脚本和逐项数据在本机的 `experiments/runtime/beside-refactor-20261121/compare.py` 与 `results.json`。

另用小白龙和 Vita 各做了 14 组函数级对照，覆盖人脸参照缺失、侧边裁切、单侧被挡、仅见隔板和两侧均无空间。两版在 23 组中给出完全相同的脚点与倍率，其余 5 组都返回无可用位置。逐项数据在同目录的 `edge-cases.json`。

原先只调用退役接口的测试已更新为覆盖正式入镜与跟随入口。完整本地回归 `python -m unittest discover -s tests -v` 共 189 项，全部通过。
