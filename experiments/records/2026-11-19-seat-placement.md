# 小白龙能否自己坐到沙发或长凳上

2026-11-19，Asia/Shanghai。当前合照模式已经入镜、角色站定后，只说“坐下”的 4 次试验，最终画面自然落座 0 次。明确说出家具名称的 2 次也都失败。结论限于本轮两张公开照片、两个固定起点和六次独立回复。

## 逐次结果

## 条件与判读

- 使用当前工作区，父提交为 `a9fafa9130bca914d739a998aefbb32ac79fe8cc`。工作区包含未提交的双模式客户端、动作和小白龙素材。本轮沿用其提示词、图库与渲染代码。合照 system 文本的 SHA-256 为 `14ee5770d3cc012ccf948854a071eb0ee239f5342da4374251ba95c4e26baeda`，6 个服务请求元数据中的值完全相同。小白龙 catalog 的 SHA-256 为 `1bf88b9af12c06e33147a7070fc3e115ecf2bea4a3a95fdd281950a4fc4d2d00`。
- 运行实时客户端使用的 `deepseek-flash`，流式、thinking=low、max_tokens=4096、timeout=90 秒，沿用服务端默认采样。返回模型为 `deepseek-flash`，服务指纹为 `bc19ba97cbe016479903222bb1578db6`。每次从相同站姿起步，独立会话，无先前示例。提交实际系统提示、口令、含角色的 JPEG（质量 80）及客户端生成的脚点信息，使用原流式分发和快门合成路径。
- 两张空家具实拍照作为固定相机帧，使用现有的人体分割及障碍物图层。沙发按比例缩为 640 × 960，起始脚点 (0.19, 0.91)。长凳为 960 × 721，起始脚点 (0.17, 0.92)。长凳底图中无真人，客户端仍附加了“全身”取景字段，保留该实际输入。实验预置入场后的站位，覆盖用户发出坐下指令后的单轮行为。[沙发底图，Alex Tyson](https://www.pexels.com/photo/sofa-in-living-room-19966798/) · [长凳底图，Yaseen](https://www.pexels.com/photo/empty-brown-wooden-bench-in-a-park-1657097/)
- 图片以左上为原点，坐标单位为合成帧像素。合格需要实际切成坐姿，臀部和支撑手落在可用座面，腿在前沿自然垂下，人物大小、遮挡关系与家具吻合。照片中的空闲座位都可接受。人工选取的右沙发垫 (425, 690) 和长凳中部 (484, 455) 仅用于报告误差。用坐姿立绘双掌间的参考点 (545, 843) 经实际绘图变换求投影，再查看完整合成图。[坐姿素材说明](../../models/avatars/README.md)

## 手工落点对照

在相同的两张图上，另做 2 次本地诊断，手工指定座面与角色大小，通过当前客户端执行坐姿和传送。沙发投影站高设为 365 像素，长凳设为 120 像素。两次实际支撑点分别为 (424.8, 689.9)、(484.5, 454.9)。长凳上的坐姿、尺度和接触关系可成立。沙发的支撑点也能对齐，但沿用默认图层时，面部与躯干仍被背景局部遮住。这两张对照未参与模型成功率统计。

## 复现

从项目仓库根目录运行下列命令。照片使用 [Pexels](https://www.pexels.com/license/) 的 960 像素宽 JPEG，作品编号分别为 19966798、1657097。本机底图、哈希与来源、每轮原始返回、实际系统提示和合成结果位于忽略目录 `experiments/runtime/20261119-seat-test/`。每次运行生成新的时间戳子目录。公开仓库保留[回放脚本](../scripts/seat_placement.py)。

```powershell
$seatImages = 'experiments/runtime/20261119-seat-test'
python -m experiments.scripts.seat_placement "$seatImages/sofa.jpg" --x 0.19 --y 0.91 --send
python -m experiments.scripts.seat_placement "$seatImages/bench.jpg" --x 0.17 --y 0.92 --send
python -m experiments.scripts.seat_placement "$seatImages/sofa.jpg" --x 0.19 --y 0.91 --text 请坐到沙发上 --send
python -m experiments.scripts.seat_placement "$seatImages/bench.jpg" --x 0.17 --y 0.92 --text 请坐到长凳上 --send
```

前两条各执行两次，后两条各执行一次。手工对照可将对应命令中的 `--send` 替换为沙发的 `--manual-seat 425 690 365` 或长凳的 `--manual-seat 484 455 120`。
