# 合照立绘库

小白龙向画面右侧探身时有两种表情，默认以微笑入场，合照时可以切换为龇牙笑。[小白龙图库](white_dragon/catalog.json)

[Vita 图库](vita/catalog.json) 收录了 90 张透明 PNG，覆盖三种脸部、两种手势、三种手臂位置、两种上半身姿势和三种腿部姿势。背手时手指被身体遮住，库中这一姿势只提供“无动作”。其余组合各有一张立绘。侧倾方向以观看画面的人为准。

Vita 入场时向画面右侧探身，双脚站立、手臂自然下垂，面带微笑。

## 添加自己的立绘

准备 8 位 RGBA 透明 PNG 和 UTF-8 编码的目录文件，用 `--sprite-catalog` 指定该文件。文件名可以自定，也可以用相对于目录文件的子路径。每组标签只登记一次。

入场会优先选 `torso=半身歪斜向右` 的立绘。有多张探身图时，依次优先选站着、手部无动作、手臂自然下垂和微笑。条件相同取目录中靠前的一张。库中没有探身图时，使用目录中的第一张。

```json
{
  "sprites": [
    {
      "file": "stand.png",
      "tags": {
        "face": "微笑",
        "hand": "无动作",
        "arm": "自然下垂",
        "torso": "正着站",
        "legs": "站着"
      },
      "standing_height_px": 600,
      "anchor_px": [100, 620]
    }
  ]
}
```

| 字段 | 允许值 |
| --- | --- |
| face | 微笑、龇牙笑、高冷表情 |
| hand | 比耶、无动作 |
| arm | 自然下垂、伸直举高过头、背在身后 |
| torso | 正着站、半身歪斜向右 |
| legs | 站着、坐着、蹲下 |

`standing_height_px` 是按该图绘制比例量出的直立身高，从鞋底量到头顶。若多张图按同样的身体比例绘制，这个数在站立、坐下、蹲下、举手时保持相同。若把整张图缩小一半，这个数也要减半。

`anchor_px` 是脚底在图上的地面接触点，通常取两脚鞋底之间。以图片左上角为原点，单位是像素，坐标可落在图片底边。裁透明边后要重新计算此坐标。图中举起的手或向右探出的肩膀可以伸出站立身高或偏离脚底中心。

小白龙的长角和头发会高出脸部。可选字段 `face_box_px` 按 `[左, 上, 右, 下]` 标出图中眼睛到下巴的区域，左右边界取两颊，不含头发、角和配饰。客户端在入场或重新定位时用框宽参照真人定尺，也用这块区域检查侧探时脸是否可见。角色站定后，原地换姿势沿用同一个脚点和画面站高，按新图的 `anchor_px` 和 `standing_height_px` 绘制。探身、坐下等姿势自身的高度差由原画决定。

重新运行客户端后，模型就能看到更新后的可用组合。

## 小白龙立绘

侧探时，小白龙两脚站得较近，鞋间留出空隙。她从髋部向画面右侧倾身，肩和脸一起探出，一只手轻靠衣领。微笑和龇牙笑共用这个姿势。绘制其他姿势时，以原稿的肤色、白裙、发饰和头身比例为准。[侧探微笑立绘](white_dragon/peek-right.png)

龇牙笑版本的双眼弯成月牙，嘴角扬起，露出一排小白牙。切换指令为 `<tachie:face=龇牙笑,hand=无动作,arm=自然下垂,torso=半身歪斜向右,legs=站着>`。改回 `face=微笑` 即可恢复入场表情。[龇牙笑立绘](white_dragon/peek-right-grin.png)

正站时双脚并拢，双臂垂在裙侧，手指微弯。参考图中的平静闭口表情登记为 `高冷表情`。切换指令为 `<tachie:face=高冷表情,hand=无动作,arm=自然下垂,torso=正着站,legs=站着>`。[自然正站立绘](white_dragon/stand-relaxed.png)

单膝蹲沿用正站的表情，画面左脚踩实，另一侧膝盖落地，一只手搭在抬起的膝上。切换指令为 `<tachie:face=高冷表情,hand=无动作,arm=自然下垂,torso=正着站,legs=蹲下>`。[单膝蹲立绘](white_dragon/kneel.png)

桌沿坐姿按真人示范绘制，双手在髋侧撑着桌面，一条腿稍向前，双脚垂在桌沿下。切换指令为 `<tachie:face=高冷表情,hand=无动作,arm=自然下垂,torso=正着站,legs=坐着>`。图库的 `seat_contact_px` 记录两掌间的支撑点 `[545, 843]`。在已识别的桌上落座时，客户端把该点投影到实际前沿，裙摆和小腿可以自然垂落；鞋底锚点仍然用于绘制。[桌沿坐姿立绘](white_dragon/sit-table-edge.png)
