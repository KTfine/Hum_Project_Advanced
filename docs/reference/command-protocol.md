# 模型文本标签协议

标签位于 API 返回的流式文本中。客户端通过 `StreamingCommandParser` 拼接分块，在每条完整标签闭合后执行。格式与参数校验见[解析器](../../photo_assistant/protocol.py)。

## 当前标签

| 格式 | 含义与校验 |
|---|---|
| `<speak:内容>` | 非空文本；当前只打印，不播报 |
| `<blank>` | 无需回应；不带参数 |
| `<capture>` | 无参数。用户要求拍摄时保存一张照片。指导模式拍摄摄像头原图，合照模式拍摄包含角色的合成画面 |
| `<wait:feedback>` / `<wait:capture>` | 真人回合登记一项需要看后续画面的任务。feedback 用于反馈或完成明确交代的跨模式调整；capture 用于在约定条件出现时拍一张。登记时不会保存照片 |
| `<mode:guidance>` / `<mode:co-photo>` | 请求任务切换；同模式请求不重复重建 |
| `<teleport:x=0.35,y=0.85>` | 当前帧的目标脚点。必填 `x`、`y` 的范围为 -2 到 3。可选 `depth=alongside\|near\|far` 切换景深；可选 `scale` 范围 0.1 到 3 |
| `<follow>` | 无参数。根据当前画面判断一次。已在真人身边时保持原位，需要换位时传送到身旁并站定。适用于半身照和全身照 |
| `<rotate:to,value=10,ms=300>` | 绝对角度，value 为 -180–180 |
| `<rotate:by,value=-5,ms=300>` | 相对角度，value 为 -180–180 |
| `<tachie:face=微笑,hand=无动作,arm=自然下垂,torso=半身歪斜向右,legs=站着>` | 按五项标签精确选择一张立绘，整组立即生效 |
| `<layer:to,index=1>` | 立即将角色移到指定层。index 表示角色后方的实景层数，取从 0 到当前实景层数的整数 |

实景层按从后到前的顺序列在合照初始状态的 `scene_layers` 中。默认摄像头使用 `["obstacle", "person"]`。index=0 时角色在障碍物和真人身后，index=1 时角色在障碍物前、真人身后，index=2 时角色在两者前。自定义图层顺序以当前 `scene_layers` 为准。两项连续指令 `<layer:to,index=1><capture>` 会按新层次拍照。

切换立绘时，一条 `tachie` 标签必须写齐以下五项，每项出现一次，每次取一个值。客户端将标签解析为一个以字段名为键的字典，在已加载的立绘库中精确查找整组。字段顺序不影响查找。漏项、额外字段、重复字段、未知值或库中缺图均保持当前立绘。

| 字段 | 可选值 |
|---|---|
| face（脸部） | 微笑、龇牙笑、高冷表情 |
| hand（手部） | 比耶、无动作 |
| arm（手臂） | 自然下垂、伸直举高过头、背在身后 |
| torso（上半身） | 正着站、半身歪斜向右 |
| legs（腿部） | 站着、坐着、蹲下 |

实时客户端自动处理入场。全身照默认自然正站，选择真人左边或右边的近邻空位，两人鞋底高度接近。半身或头肩照从真人身体或前景障碍物侧边探出，预览在落点播放传送光效。找不到合适位置时等待下一帧。无相机时显示起始立绘。

模型可在同一轮换图和传送。例如 `<tachie:face=微笑,hand=无动作,arm=自然下垂,torso=半身歪斜向右,legs=站着><teleport:x=0.75,y=0.90>` 选用向右探身的立绘，以当前画面的指定脚点换位。只换表情时，完整标签中沿用其余四项。

传送使用整幅画面的归一化坐标，左上角为 (0, 0)，右下角为 (1, 1)。初始景深为 `alongside`。客户端在入场或收到身旁落点请求时，用当时的真人定尺。落地后保存脚点和投影大小。真人走开时，默认侧探立绘会在原地换为自然正站。显式选择的姿势和图层按用户指令保留。

用户明确让小白龙自己靠近或远离镜头时，分别使用 `depth=near` 或 `depth=far`。两者均固定离开身旁时的大小基准，默认倍率为 1.35 和 0.70，可用显式 `scale` 指定倍率。后续省略 `depth` 会维持当前模式。用户说“跟过来”时用 `<follow>`。指定坐标时仍使用 `teleport`。半身合照横移后拍摄的示例为 `<teleport:x=0.5,y=1.8><capture>`。自动观察回合会忽略传送、跟随、换图、旋转和图层指令。快门和模型图像都使用目的地的清晰立绘。

所有数值均须有限。未知参数、重复参数、缺少必需参数或数值超限都会使整条指令失效。`ms` 仅适用于旋转，默认为 350，范围为 0 到 3000 的整数。相对旋转基于上次的目标角度累加，最终角度限制在 -180 到 180 度。换图时保留构图位置。

## 流式与适配

例如 `<speak:我到右边来。><teleport:x=0.7,y=0.9>` 可单行连续输出。标签可跨网络分块，每条完整闭合后立即解析执行。未知、非法和未完成标签不猜测执行。

用户明确要求拍下当前画面时，模型可输出 `<capture>`。实时客户端读取指令执行时最新的摄像头帧，合照模式按当前姿势、表情和遮挡关系合成照片。照片按摄像头分辨率写为无损 PNG，保存在项目的 `photos/` 目录中。没有可用相机帧时跳过该次拍摄。

在内置模式中，没有待办时，后续摄像头帧只用于预览和准备下一次对话。等待反馈的回合会忽略快门指令；等待拍摄的回合最多执行一次快门。用户的新输入会取代旧待办。独立图文实验会向调用方返回 `wait` 指令，由调用方决定何时提供下一张图片。

解析器默认严格模式，普通客户端使用 `allow_plain_speech=True` 将标签外文字增量适配为 speak，记录 `parser.plain_text_adapted`。自然语言不会被推断为动作或模式。判断原生标签质量必须检查原始输出。

指导模板不提供角色动作，但客户端没有按模式禁止合法动作；指导期间意外生成的动作仍会改变隐藏的角色状态。模板约束和运行权限是两个不同层次，不能声称已经硬性隔离。

## 切换与旧入口

mode 标签先记录 `session.mode_requested`。新本地会话就绪后记录 `session.mode_ready` 并更新画面。切换保留摄像头连接，每次进入内置合照都使用本库的入场姿势，并根据当前画面重新定位。自定义 prompt 使用自己的模板。

`<photo:enter>` 只保留历史解析兼容；分发时记录 `command.skipped`，原因 `legacy_photo_entry_use_mode_tag`，不入画、不切换。基于旧版 `move` 或独立 `scale` 动作的自定义模板及调用方应改发一条含绝对落点的 `teleport`。
